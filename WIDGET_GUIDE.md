# Spider Clock — Real Widget Guide

## PC (Windows EXE) — desktop widget that stays

1. Run `SpiderClock-Windows.exe`
2. The clock opens and stays **always on top** (widget mode)
3. Closing the window **hides it to the system tray** — it does **not** quit
4. Right-click the tray icon:
   - **Show / Hide**
   - **Desktop widget mode** (always on top)
   - **Start with Windows** (spawns after reboot)
   - **Exit** (only way to fully remove until you open the EXE again)
5. Drag to move, resize from edges — position is remembered

## Android APK — real home screen widget

1. Install `SpiderClock-Android.apk`
2. Open the app once (animated full clock)
3. Long-press empty home screen → **Widgets**
4. Find **Spider Clock** → place it
5. It **stays on the home screen until you remove it**
6. Tap the widget to open the full animated app

### Note on Android widgets
Home-screen widgets use Android’s App Widget API (time + branding).  
The **full spider gear animation** runs inside the app (same as Rainbet-style: widget on home, rich UI when opened).
